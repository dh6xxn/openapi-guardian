# Security Policy

## Supported versions

OpenAPI Guardian is currently pre-1.0. Security fixes are prioritized for the latest release on the default branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Instead, contact the repository maintainer privately through GitHub with:

- A description of the vulnerability
- Steps to reproduce it
- Affected command or component
- Any relevant proof-of-concept details

Please do not include real credentials, API tokens, customer data, or other secrets.

We will investigate reports as soon as reasonably possible and coordinate disclosure when appropriate.
